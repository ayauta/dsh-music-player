# Triage labels

技能用五个规范分诊角色说话；本文件把角色映射到本仓库实际使用的标签串（写在 issue 文件的 `Status:` 行）。

| 角色（mattpocock/skills） | 本仓库标签串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估 |
| `needs-info` | `needs-info` | 等报告者补信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人来做 |
| `wontfix` | `wontfix` | 不做 |

本地 Markdown tracker 下"打标签"= 改写 issue 文件靠上的 `Status:` 行；不改文件名、不建额外索引。
