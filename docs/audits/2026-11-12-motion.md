## 2. 发现

| ID | 严重度 | 发现 | 违反的条文 | 证据 |
|---|---|---|---|---|
| M01 | 高 | 面板**没有退出动画**：`dshm-pop-out` 与 `[data-closing="true"]` 存在，但整份代码没有任何地方写入 `data-closing`，关闭即卸载 | Spatial consistency：进出同一路径；"preventing jarring change" | client.js:498 定义，全文件无写入点 |
| M02 | 高 | **一条曲线走天下**：drawer 曲线同时用于 90ms 按压、130ms 颜色、160ms 浮层、150ms 开关 | Easing 决策顺序：进入/退出 ease-out、hover/颜色 ease、移动 ease-in-out | client.js:386 / 404 / 440 / 497 |
| M03 | 中 | 按压 90ms 低于 100–160ms 区间 | Duration：Button press feedback 100–160ms | client.js:404 |
| M04 | 中 | 进度轨用 **height** 做 3→5px 过渡，触发 layout | Performance：只动 transform / opacity | client.js:466 |
| M05 | 中 | 卡片封面 hover 过渡 **box-shadow**，逐帧 paint | Performance：只动 transform / opacity | client.js:606 |
| M06 | 低 | 死动效代码：`dshm-rise` keyframes 从未被引用 | 维护性：未引用动效即缺陷 | client.js:675 |
| M07 | 低 | 浮层入用 **keyframes** 而非 transition，快速开关会从零重播；面板为可逆 UI | Interruptibility：可逆 UI 用可中断的 transition | client.js:497 |

## 3. 做对的部分（不要回退）

- 进入 `scale(.97)` + `opacity: 0`，没有 `scale(0)`；`transform-origin: bottom left` 与迷你行锚点一致。
- 进 160ms / 出 120ms 的不对称思路正确（退出应当更快）。
- `prefers-reduced-motion` 关闭了位移、按压缩放与进度过渡；`prefers-contrast: more` 加粗进度轨。
- 除 M04 / M05 两处外，其余动效都在 transform / opacity / color 上。

## 4. 结论

骨架是对的，问题集中在**曲线分工、退出动画缺失、两处布局/绘制属性、死代码**。
修复顺序建议：M01 + M07（一起做，可逆的进出）→ M02 + M03（曲线与时长令牌）→ M04 / M05（换属性）→ M06（删）。
规范见 `docs/DESIGN.md` §6，测试见 `docs/TESTING.md` §2.4。

## 5. 复核（2026-11-12 晚，实机反馈）

用户实机观察：开的时候看得到，**关的时候感知不明显**；迷你播放器播放/暂停按钮**像卡住**；悬停手感好。

| ID | 发现 | 依据 | 处理 |
|---|---|---|---|
| M08 | 退出 120ms + 6px / 1.5% 缩放的位移量太小，视觉上接近瞬断 | NN/G：消失应短于出现，整体 100–500ms，简单反馈约 100ms，画面级变化 200–300ms；Apple HIG：反馈要 brief and precise | 退出改 **160ms**，位移放大到 `translateY(12px) scale(.94)`；进入提到 **200ms**、起始 `scale(.96)` |
| M09 | 按下与松开同用 120ms，按下感受不到"即时"，松开又拖 | Apple HIG：Respond on pointer-down, not on release；emil：`scale(.97)` + `ease-out` | 按下 **110ms**、松开 **160ms**（`:active` 内覆盖 `transition-duration`） |
| M10 | 播放/暂停图标等主机回包才翻转：`command()` = `call()` + `refreshStatus()` 两次往返，暂停还要等 mpv 确认 | Apple HIG：任何非必要延迟都是回归 | 乐观图标：按下立即翻转，快照一致即清除，1.5s 超时兜底 |

来源：`developer.apple.com/design/human-interface-guidelines/motion`（Markdown 版）；
`nngroup.com/articles/animation-duration/`（100–500ms；简单反馈约 100ms；出现 200–300ms、消失更短）。
