# 播放面板版式调研与裁定 · 2026-11-12

对象：`client.js` 的 `dshm-pop`（约 300px 宽浮层）。**本文件是决策记录，不是规范**；
规范已落到 `docs/DESIGN.md` §7。

## 1. 证据等级（先声明）

- **一手**：Apple HIG `Motion` / `Layout`（`developer.apple.com/.../*.md`）；
  本地 `apple-design`、`emil-design-eng`（`.dsh/skills`，`715c180`）。
- **二手**：优设《10 个音乐产品细节剖析》逐家点评（[链接](https://www.uisdc.com/10-ui-ux-design-9)）。
- **产品常识**（未逐帧核对截图）：五家国内播放页的控件骨架。
- 没有拿到五家的官方设计规范；因此只借骨架，不借皮肤。

## 2. 五家在比什么

| 产品 | 骨架 | 差异化 | 可取 | 不适用 |
|---|---|---|---|---|
| 网易云 | 封面/黑胶 + 标题 + 进度 + 三键 + 次级操作 | 黑胶、磨砂玻璃、皮肤 | 骨架纪律 | 旋转黑胶在 300px 桌面浮层里是噪音 |
| QQ 音乐 | 同上 + 轻拟物 | 封面取色的弥散光 | 氛围可选 | 与宿主主题抢色（D-22） |
| 酷狗 | 同上 | 主题/视频皮肤 | — | 皮肤商店 |
| 酷我 | 同上 | 3D 主题 | — | 同上 |
| 汽水 | 大封面 + 极少 chrome | 播放键气泡动效 | **少控件、大封面** | 全屏沉浸与滑动换歌不适合浮层 |

结论：五家的骨架与 Apple 同源；差异化在皮肤与氛围，而这两样我们**明确不做**。
所以能借的只有：封面优先、三键传输、次级操作与传输分离、进度条轻量化。

## 3. 当前实现（改动前）

| 项 | 值 | 问题 |
|---|---|---|
| 面板宽 | `min(300, vw-24)`，最小 256 | 无 |
| 内容边距 | body 18px，meta 再 +2px | 标题比封面多缩进 2px，肉眼可见不齐 |
| 封面 | 264×264，圆角 12 | 与卡片（10）不同族 |
| 节奏 | 12 / 10 / 12 / 12 | 不成体系 |
| 传输行 | 四键 `space-between`（含模式） | 传输语义被设置键污染 |
| 进度条 | 滑块常显 | 像表单控件 |
| 音量 | 轨 4px、与进度条同重 | 两条滑杆互相抢 |

## 4. 三个方案

- **A 苹果式**：去可见标题；三键居中；模式进 header；16px 边距；封面 268；音量降权。
- **B 双区**：传输三键 + 底部 `[模式] … 音量短轨`。音量行程变短。
- **C 内容头**：header 变 `[封面 | 队列]` 分段控件，等于同时做 R06。

**用户裁定（2026-11-12）：A**，C 留给 R06 那次一并做。

## 5. 八条裁定

1. 面板宽 300 固定（窄视口 256 兜底）
2. 封面贴满内容宽（268），不缩到 240
3. 左右边距统一 16px，封面与文字同一条线
4. 删除可见「正在播放」，保留 `aria-label`，位置预留给 R06
5. 传输行三键居中，模式键移到 header；尺寸 52 / 40 / 40
6. 进度滑块只在悬停/拖动出现，命中区 20px
7. 音量保留全宽但降权（3px / 10% / 滑块 hover）
8. 先落 A

## 6. 落地对照

| 规范 | 实现 |
|---|---|
| 无可见标题 | header 只留折叠、模式、队列；`aria-label` 不变 |
| 三键居中 | `.dshm-pop-transport { justify-content: center; gap: 18px; padding-top: 16px }` |
| 模式进 header | `ModeButton` 移入 `.dshm-pop-head` |
| 16px 边距 | body `0 16px 16px`；meta `14px 0 0` |
| 封面圆角 10 | `.dshm-pop-art { border-radius: 10px }` |
| 进度滑块按需 | 删除 `.dshm-pop .dshm-progress-thumb { opacity: 1 }` |
| 音量滑块 | 按 HIG Sliders 还原为标准形态：轨 3px（槽 12%）、填充主色、**常显滑块 12px**、左侧扬声器图标（最小值图标） |
| 模式键 | 去掉 `data-active` 背景：HIG Buttons 里填色背景属于 prominent 样式，一屏最多一两个；四态由图标形状表达 |
| 进度滑块 | 改为常显：HIG Sliders 的 thumb 是控件本体 |
| 传输键悬停 | **更正**：桌面图标按钮需要系统式 hover 高亮（HIG · Toolbars）。保留 8% 中性底色，形状统一为圆角矩形（macOS 语境），不加阴影 |
| 传输三键尺寸 | 统一 44×44、圆角 12：HIG Buttons 明确「不要用尺寸区分并列选项」；播放键只放大字形（20 vs 18），不放大按钮 |
| 控制组间距 | 传输上 10、音量上 6（视觉约 28），替代原先的两个 16 |

## 7. 未覆盖

- 没有在 1.25× / 1.5× 字体缩放与 100% 缩放下复验；
- 没有录屏判读面板整体节奏；
- 队列视图（R06）未做，header 中央仍留白。
